# CodeAlpha_Chatbot

A simple rule-based chatbot built in Python as part of the **CodeAlpha Python Programming Internship** (Task 4).

## Description

The chatbot reads messages typed by the user and replies with predefined responses. It keeps running in a loop until the user types `bye`.

## Features

- Responds to predefined inputs such as "hello" and "how are you"
- Case-insensitive input (`Hello`, `HELLO` and `hello` all work)
- Gives a fallback reply when it doesn't understand a message
- Reply logic is kept in a separate function
- Exits cleanly when the user types `bye`

## Concepts Used

- `input()` / `print()` for console input and output
- `while` loop to keep the conversation going
- `if-elif-else` to choose replies
- Functions (`def` and `return`)
- String methods such as `.lower()`

## How to Run

1. Make sure Python 3 is installed: `python --version`
2. Clone this repository:
   ```
   git clone https://github.com/[your-username]/CodeAlpha_Chatbot.git
   ```
3. Move into the folder:
   ```
   cd CodeAlpha_Chatbot
   ```
4. Run the program:
   ```
   python chatbot.py
   ```
